# ⚡ On-Demand EV Charging Service

An on-demand service connecting electric vehicle drivers with nearby homeowners and charging providers who have been registered with the system.

Drivers will be able to locate available charging providers, see prices, and make booking requests. Providers will then be able to accept or decline booking requests, and booking will be done once request is accepted.

### Key Functions
- Location search for providers
- Provider’s availability
- Booking requests and booking confirmation
- Prices visibility
- Payments tracking
  
### Objective
Making charging services easy-to-use and profitable for both sides of the interaction.
